# Portfólio pessoal — Arthur Silvani

Este projeto é um exercício prático de **React**: um portfólio pessoal criado para colocar em prática os conteúdos estudados em aula e apresentar um pouco sobre mim, meus interesses e meus objetivos como futuro desenvolvedor.

## Sobre o projeto

A estrutura inicial e a base do código foram disponibilizados pelo Prof. Matheus Barquette. A partir desse ponto, o desafio foi personalizar o projeto: montar meu portfólio, trabalhar a estilização e acrescentar elementos e funcionalidades para deixá-lo com a minha identidade.

O resultado reúne informações pessoais, tecnologias que estudo, atividades de que gosto e uma frase que me inspira. Também inclui links para meus perfis profissionais e uma identidade visual em tons de verde.

## O que pratiquei

- Criação e composição de componentes em React.
- Passagem de informações entre componentes por meio de props.
- Exibição de listas de tecnologias e interesses.
- Organização dos estilos em arquivos CSS.
- Personalização visual com uma paleta de cores própria.
- Links para meus perfis no LinkedIn e no GitHub.
- Efeitos visuais de interação nos links e nas tecnologias.

## Tecnologias

- React
- JavaScript
- CSS
- Vite

## Como executar

Você precisa ter o [Node.js](https://nodejs.org/) instalado.

1. Clone este repositório:

   ```bash
   git clone https://github.com/ArthurSilvani/Portifolio-emReact.git
   ```

2. Entre na pasta do projeto:

   ```bash
   cd Portifolio-emReact
   ```

3. Instale as dependências:

   ```bash
   npm install
   ```

4. Inicie o servidor de desenvolvimento:

   ```bash
   npm run dev
   ```

O Vite mostrará no terminal o endereço local para abrir o projeto no navegador.
